# AI YouTube Study Assistant

AI YouTube Study Assistant is a web application that converts YouTube lectures into easy-to-understand study material using Google's Gemini AI. Simply paste a YouTube video URL, and the application extracts the transcript and generates an AI-powered summary.

## Features

- Paste a YouTube video URL
- Automatically extract the video transcript
- Generate AI-powered summaries using Gemini AI
- Clean and responsive web interface
- Fast and simple workflow

## Tech Stack

- Node.js
- Express.js
- EJS
- Gemini API
- YouTube Transcript API

## Installation

```bash
git clone https://github.com/imsumitsandhu/Youtube-Study-App.git
cd Youtube-Study-App
npm install
```

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Start the application:

```bash
npm start
```

Open:

```
http://localhost:3000/youtube
```
